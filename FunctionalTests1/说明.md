# Functional Test 作业使用说明

这份作业包含可重复调用的 Python 风险管理包、老师测试的运行脚本、独立验证、
实际计算出的 CSV 答案和测试报告。`ANSWER.md` 是英文结果说明。

本次实现 23 项：1.1–1.4、2.1–2.3、3.1–3.4、4.1、5.1–5.5、7.1–7.6。
这是老师当前 checkpoint 的范围，并包含后来新增的 NIG 7.5（矩估计）和 7.6（最大似然估计）。
**没有实现整个清单的 50 项。** pytest 总数 50 指 23 个老师案例加 27 个额外检查，
不能理解为老师清单的 50 项都已完成。

在终端进入此文件夹，按 README 安装依赖后运行：

```bash
python run_functional_tests.py
python -m pytest -q
```

第一条命令实际重新计算 23 个结果，写入 `output/`，并显示逐题 PASS/FAIL。
第二条命令运行 23 个指定案例和 27 个额外检查。额外检查是模拟老师可能直接调用函数、
换输入、换随机种子的验证方式，并不是声称老师会使用隐藏测试。

`data/` 中是老师原始输入与参考答案。`output/` 中是自己函数计算出的答案。
`risk545/` 中的函数不读取答案文件，也没有将标准答案硬编码进去。
数值优化和随机模拟采用 README 中事先说明的容差；老师没有在字幕里给出确切数值容差。

提交时应包含这个文件夹里的包、测试脚本、数据、README 和结果报告；只交 CSV 或
只交一份 PDF 无法体现老师要求的“调用 package 并运行测试”。不要提交 `.venv`、
缓存或 Python 安装环境。通常将此目录提交到自己的 GitHub 仓库，让老师能运行代码。
本次生成文件和本地验证不等于已经推送到 GitHub。

本题与之前的 Assignment 1 书面分析作业分别存放。以后 checkpoint 新增的测试应
继续加入同一个可复用库和一键运行程序中。
